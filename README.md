# LifeOS — Everything in life, organized in one place

Local-first personal dashboard with multiple user profiles (optional PIN), time-of-day greeting and personalization (name, currency, accent colour, light/dark, choose your modules): tasks, money, subscriptions, goals, habits, important dates, reports, dark/light theme, JSON backup/restore, CSV export. No backend, no accounts.


- Data lives in your browser on one device. Use **Settings → Export backup** regularly and **Restore backup** to move devices.
- Clearing browser data erases your workspace — keep a backup.
- Start fresh via **Settings → Clear sample data**.
